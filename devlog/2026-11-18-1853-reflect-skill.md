# Route Session Lessons Into Structure With a Reflect Skill

The new `reflect` skill reads a session for corrections and stumbles and
proposes where each durable lesson should live. Issue #389 carries the
contract. Before this, lessons such as the 2026-07-18 fold-before-reply gate,
the 2026-08-03 conductor-routing note, and the 2026-09-01 ledger skeleton came
from the owner watching agents fail and routing each fix by hand.

## Decisions

- **Chose the routing order mechanism, then trigger, then prose over
  treating every lesson as a prose edit.** Prose grows with each lesson and
  agents skim it, so a rule restated in prose can still be missed. The
  2026-09-01 ledger-skeleton note shows the difference: a generated trace
  removed an error class that clearer prose and better error messages hadn't.
  A missed skill trigger is fixed where routing happens, in the description,
  not by adding body text the agent never loads.
- **Chose a separate skill over a `prompt-crafter` mode.** Reflect's input is
  a transcript, and its trigger is a request to learn from a session.
  `prompt-crafter` audits prompt files with no transcript, and its trigger
  covers how well config files work. One description holding both would blur
  routing for each. Reflect hands approved prose edits to `prompt-crafter`
  where it is available, so the prompt-writing craft stays in one place.
- **Chose drafting an upstream issue over editing an installed copy.** An
  edit to an installed or cached skill is lost on the next install or drifts
  from its source. A free-skills lesson found in another project goes to
  `freeasinbird/free-skills` as a draft shown before filing.

Revisit when a first live run shows the durability filter rejecting lessons
the owner wanted kept, or when `prompt-crafter` starts reading transcripts.
