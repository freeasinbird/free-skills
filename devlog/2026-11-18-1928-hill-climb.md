# Add a Hill-Climb Skill With a Proven, Frozen Check

The `hill-climb` skill improves an artifact against a score in measured
attempts and delivers the kept changes as a PR. Issue #390 carries the
contract. It is the first caller of council's scoring mode
(`devlog/2026-11-18-1850-council.md`).

## Decisions

- **Chose Theo's loop with pstack's discipline over either alone.** Theo's
  loop (goal, check, budget, tools, check-ins) says what a climb is for and
  when to ask the owner, but it trusts the check. pstack's hillclimb playbook
  proves the check is sensitive, freezes it, changes one thing per attempt,
  keeps or reverts, logs everything, and pairs a target with a minimum number
  of attempts. A climb that trusts an unproven check optimizes the check, not
  the goal.
- **Chose programs over references over council as check tiers.** Repeat
  judge runs give different scores, and Theo calls programmatic evals strictly
  better. A program can't drift and costs little per attempt; a reference
  comparison is next; council is the last resort, available only at a rung
  with fresh-context members, since rung 3 returns no scores.
- **Chose a cheap screen before the full panel over scoring every attempt
  with council.** Each council run costs one high-effort run per member, twice
  in scoring mode. A program or one fresh-context judge that hill-climb runs
  itself filters attempts; council never seats a single member, so the screen
  belongs to hill-climb.
- **Chose a rule plus a hash over relying on a read-only sandbox.** Most hosts
  let the climber write its own climb directory. Hashing the frozen check and
  the goal file catches a change on every host; a read-only sandbox enforces
  the rule where one exists.
- **Chose a durable climb directory outside the repository over session
  scratch space.** The report gives a log path the owner can open later, and
  attempt logs don't belong in the project's history.

Revisit when council's Scoring Contract changes, when #392 builds a reusable
eval runner that could serve as the program tier, or when a host offers a
read-only scoring sandbox everywhere.
